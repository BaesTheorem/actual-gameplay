Art in Actual Gameplay

Sprites and tiles from Kenney (kenney.nl), released under Creative Commons Zero (CC0):
  New Platformer Pack 1.1 (enemies, hazards, items, terrain, characters, backgrounds)
  Background Elements (clouds)
  Animal Pack Remastered (the dog)
No attribution is required by the license; it is given because the work is good.
Files are renamed to what they are used as; nothing is modified except naming.

Painted set (Art/painted/)
  Generated by tools/painted/render.mjs from the Claude Animation Base kit (p5.js + p5.brush,
  MIT: github.com/JohnHeibel/ClaudeAnimationBase, via the fork at ~/Documents/claude-animation).
  Clawd is the Claude Code mascot as drawn by that kit. Every file in the folder is a render of
  tools/painted/gameart.js; edit that and re-run the script rather than editing the PNGs.
